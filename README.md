# RAG-детектив · редакция 3: один notebook

Откройте `ТЗ.md`, затем `detective.ipynb`. Архив дела тот же, что в редакции 2;
изменились формат кода, сдачи и проверки. Старые ТЗ и шаблоны в эту папку не добавляйте.

## Запуск

В папке комплекта:
```bash
uv sync
uv run jupyter lab
```
В VS Code после синхронизации выберите Python из `.venv` как kernel.
Скопируйте `.env.example` в `.env.local`, заполните выбранные модели и адреса.
Ключи можно вводить через `getpass`, не сохраняя в коде. Запустите notebook сверху вниз.
В последней ячейке можно вводить новые вопросы. Не требуется отдельное приложение или сервер RAG.

`api` требует endpoint, совместимый с используемым интерфейсом. `ollama` требует заранее
запущенный локальный сервер и загруженные модели. Выбор модели ответа и embeddings независим.
Для полностью локального пути поставьте `ollama` в оба BACKEND. Другие SDK и runtime допускаются,
но тогда адаптируйте ячейки и опишите свой запуск. Шаблон не содержит ключей и не скачивает веса.

Настройки `max_tokens` / `max_completion_tokens` и контекст зависят от вашей модели.
Индекс строится один раз; повторный Run All повторяет embeddings и три модельных примера.
Для следующего вопроса достаточно запускать только его ячейку.

## Состав и сдача

`detective.ipynb` — готовая базовая связка по лекции, без разгадки и модельных результатов.
`data/` — 100 неизменённых документов, JSONL, каталог и manifest.
`case_question.txt` — главный вопрос; `evaluation/questions.jsonl` — необязательный банк вопросов.
`pyproject.toml` и `.python-version` — исходные настройки окружения; первый `uv sync` создаёт `uv.lock`.
Приложите полученный lock-файл к сдаче. `.env.example` — настройки без секретов.
Установка зависимостей этой раздатки в данной среде не проверена: сетевой доступ отсутствовал.

Сдайте выполненный `detective.ipynb` с сохранёнными outputs и итоговым заключением в Markdown-ячейках,
папку `data/` и файлы окружения. Отдельные `answer.md`, `runs/`, CLI и две конфигурации не обязательны.
Сохраните три разобранных запроса, хотя бы один из которых вы сформулировали сами, и нужные
для расследования источники. Весь материал выдаётся сразу, проверка проводится после одной сдачи.

Внутри проекта индексируется только корпус. Разгадка и файлы преподавателя не являются источниками.
Материалы вымышлены. Исходный лекционный `rag.ipynb` и программа курса этой редакцией не изменены.
